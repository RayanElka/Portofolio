# Rayan El Kaouid — Developer Portfolio

A bilingual portfolio covering my full-stack internship at Trans-IT, school projects, and mobile development work. I graduated in Programming from AP University of Applied Sciences and Arts in Antwerp and am especially interested in frontend development.

[Live portfolio](https://portofolio-five-amber.vercel.app) · [Internship devlog](https://wpl-stage-blog.vercel.app)

## Run locally

Use Node.js 24 and npm.

```sh
cd portofolio
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run build` to create a production build, then `npm start` to serve it.

## Project structure

The Next.js Pages Router lives in `portofolio/pages`. Reusable sections are in `portofolio/components`, language preferences in `portofolio/context`, styles in `portofolio/styles`, and static assets in `portofolio/public`. Use `portofolio` as the Vercel root directory.
